# Thomas Bade Website

Statische Website mit 52 Fachseiten sowie der **Knowledge Graph & GEO Platform**.

- Website: `/index.html`
- GEO-Dashboard: `/knowledge-graph/`
- Maschinell lesbare Seitendaten: `/knowledge-graph/data/pages.json`
- Knowledge Graph: `/knowledge-graph/data/graph.json`
- JSON-LD und LLM-Exporte: `/knowledge-graph/data/`

Die Veröffentlichung erfolgt über GitHub Pages aus dem Root-Verzeichnis des Branches `main`.
Open-source HTML knowledge platform for AI Governance, EU AI Act, ISO/IEC 42001 and Digital Health.
